# Harshem Family Practice

This is the official website for Harshem Family Practice, a primary care practice serving Central and Northern New Jersey. The site provides information about the practice's providers, services, office locations, and accepted insurance plans. It also features a multi-step appointment request form for patients.

Built with the [T3 Stack](https://create.t3.gg/), this project leverages modern web technologies to deliver a fast, secure, and user-friendly experience.

- [Next.js](https://nextjs.org)
- [tRPC](https://trpc.io)
- [Tailwind CSS](https://tailwindcss.com)
- [Drizzle](https://orm.drizzle.team)
